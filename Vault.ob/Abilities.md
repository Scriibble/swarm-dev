# Abilities

Active abilities, passive abilities, and evolved forms in the current catalog.

## Active abilities

- [x] Ember Bolt: IN GAME
  - Fires a directional projectile toward the mouse aim direction.
  - Deals direct damage and scales with the ability rank and the player's attack damage.
- [x] Blood Orbit: IN GAME
  - Circles the demon with a damaging blood orb.
  - Hits nearby enemies as the orb completes its orbit.
- [x] Core Pulse: IN GAME
  - Releases an area pulse around the Infernal Core.
  - Damages enemies inside the pulse radius and protects the core's position.
- [x] Hellfire Field: IN GAME
  - Creates a damaging hazard on the arena floor.
  - Remains active for a short duration and grows with rank and evolution.
- [x] Bone Spear: IN GAME
  - Fires a long-range piercing projectile.
  - Passes through multiple enemies before the pierce limit ends.
- [x] Chain Lash: IN GAME
  - Strikes the nearest target and chains to additional enemies.
  - Reduces damage across the chain unless the ability has evolved.
- [x] Imp Swarm: IN GAME
  - Summons homing imp projectiles that seek nearby enemies.
  - Increases the number of imps with rank and evolution.
- [x] Soul Drain: IN GAME
  - Damages the nearest enemy in range through a drain beam.
  - Restores health to the demon based on a portion of the damage dealt.

## Passive abilities

- [x] Emberheart: IN GAME
  - Adds 4 attack damage per rank.
  - Supports the Ember Bolt evolution.
- [x] Cinder Step: IN GAME
  - Adds 18 movement speed per rank.
  - Supports movement-focused demon builds and the Grave Magnet unlock.
- [x] Core Ward: IN GAME
  - Adds 25 maximum health to the Infernal Core per rank.
  - Supports the Core Pulse evolution.
- [x] Infernal Might: IN GAME
  - Adds 5 attack damage per rank.
  - Requires Emberheart before the profile can unlock it.
- [x] Quickened Flame: IN GAME
  - Reduces attack cooldown per rank.
  - Requires Cinder Step before the profile can unlock it.
- [x] Long Reach: IN GAME
  - Adds 25 attack range per rank.
  - Requires Emberheart before the profile can unlock it.
- [x] Soul Siphon: IN GAME
  - Adds 10% XP gain per rank.
  - Requires Core Ward before the profile can unlock it.
- [ ] Grave Magnet: NOT CURRENTLY IN GAME
  - Intended to increase pickup radius by 35 per rank.
  - Enemies grant XP directly on death in the current run, so no pickup-radius system applies this effect.
- [x] Flesh of the Pit: IN GAME
  - Adds 20 maximum health per rank.
  - Raises current health by the same amount when the upgrade increases the maximum.

## Evolved abilities

- [x] Inferno Bolt: IN GAME
  - Evolves Ember Bolt into a larger, faster, stronger projectile.
  - Keeps the directional aim behavior and adds stronger projectile feedback.
- [x] Crimson Orbit: IN GAME
  - Evolves Blood Orbit with faster movement, higher damage, and a larger orb.
  - Adds a stronger visual treatment while the orb circles the demon.
- [x] Cataclysm Pulse: IN GAME
  - Evolves Core Pulse with a larger radius and higher damage.
  - Keeps the pulse centered on the Infernal Core.
- [x] Hellstorm: IN GAME
  - Evolves Hellfire Field with higher damage and a longer hazard lifetime.
  - Uses a stronger hazard state to mark the evolved field.
- [x] Grave Lance: IN GAME
  - Evolves Bone Spear with greater pierce, speed, size, and damage.
  - Keeps the long-range piercing behavior.
- [x] Writhing Chain: IN GAME
  - Evolves Chain Lash to reach more targets with less damage falloff.
  - Uses a wider, brighter chain effect.
- [x] Greater Swarm: IN GAME
  - Evolves Imp Swarm by adding more imps and increasing their damage.
  - Uses a stronger color treatment for the evolved projectiles.
- [ ] Soul Furnace: NOT CURRENTLY IN GAME
  - Intended to evolve Soul Drain into a stronger drain and healing attack.
  - Choosing this evolution records it, but Soul Drain keeps its base behavior.
