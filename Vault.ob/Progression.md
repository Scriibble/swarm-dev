# Progression

## During a run

You start at level 1. The first level needs 12 XP. Later thresholds rise with your level.

Each level gives you three upgrade choices. You can raise an ability or passive to rank 5. A planned evolution can appear after its ability reaches rank 5 and you have the matching passive.

Run upgrades disappear when you start again.

## A new profile starts with

**Demon:** Ash Summoner

**Abilities:** Ember Bolt, Blood Orbit, Core Pulse

**Passives:** Emberheart, Cinder Step, Core Ward

## Stronghold unlocks

| Group | Available choices |
|---|---|
| Demons | Ash Summoner is free. Core Bulwark costs 50 Shards. Blood Harbinger costs 75. |
| Abilities | Ember Bolt, Blood Orbit, and Core Pulse are free. Hellfire Field costs 25, Bone Spear 30, Chain Lash 35, Imp Swarm 40, and Soul Drain 45. |
| Passives | Emberheart, Cinder Step, and Core Ward are free. Infernal Might costs 20, Quickened Flame 25, Long Reach 25, Soul Siphon 30, and Grave Magnet 20. |

Some unlocks require another unlock first. The game saves purchases in `user://profile.save`.

Permanent progress changes which content you can start with. It does not raise your combat stats between runs.

## Run rewards

At the end of a run, the game adds Shards for survival time, kills, and the core's remaining health. A victory adds 20 more Shards.

The profile records kills, runs, victories, and total survival time.
